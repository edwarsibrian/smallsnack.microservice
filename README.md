# smallsnack.microservice
The application is configured to use the Entity Framework Core InMemory provider which allows EF Core to create and connect to an in-memory database rather than you having to install a real database server.
For run the application locally download and install the following: .Net Core SDK, Visual Studio 2017 or 2019
 
Note: all immediate changes are pushed in develop branch also it create a pull request to master branch and merged.
